free-radio-foobar

I recently discovered you can set up a fun, customizable, capable internet radio listening experience without purchasing anything.

The program is foobar2000. It's classic freeware. I'd heard of it before but I haven't maintained a library of local music files in like 10 years, so I never had much reason to download it until recently when I wanted to try the new album from King Gizzard & The Lizard Wizard. They removed their catalog from Spotify a while back, but all their albums are available at "name your price" on Bandcamp.

I wanted a program that wasn't just Windows Media Player, and it turns out VLC (which I already use for video) doesn't do gapless playback for audio. Figured this is my chance to try out foobar.

And, well, it's really cool! And it does radio too.

It's ancient and modular. The standard version of the program is a collection of built-in components, and you can add whatever community-made components you want on top of that. You can go fully custom for themes/skins/icons and layout as well.

I set mine up so I could throw it on my portrait monitor. Here are my UI components:

  1. Album List. Built-in. Shows local media. I pointed mine at the 4 KGLW albums I downloaded.
  2. Selection Properties. Built-in. Metadata for the "selected" track. When radio is playing this shows info about the current station.
  3. Playlist View. Built-in. Basic track-by-track view of your current playlist, or artist/trackname info for the current radio track.
  4. OpenLyrics Panel. Community-made. Uses the current track name and artist info to search a few online sources for lyrics. Depending on source this can also time the display to auto-scroll and highlight lyrics as the song progresses. Mine favors Genius, and I've turned off scrolling.
  5. Internet Radio. Built-in. Lets you search, bookmark, and tune in to whatever public internet radio stations you want. Right now I have KEXP, NPR, and WBEZ Chicago.
  6. Artwork Display. Community-made. Uses the current track name and artist info to search online sources for album artwork, when local artwork isn't found. I also have the built-in EQ component on another tab here.
  7. Spectrogram, Oscilloscope, and Spectrum Analyzer. All built-in. The Spectrogram is using the 2-channel view and has custom orange coloring. The Oscilloscope is downmixing to mono, with a 200ms curve duration. Spectrum analyzer uses 160 bands.

I've also set up a community-made scrobbling component for LastFM. It sets "now playing" for radio but does not save the scrobbles. Listens from local files are scrobbled. I only want my more intentional listening tracked, but don't mind sharing what I've got playing on the radio, so this does exactly that.

End result is a neat display I leave off to the side, with fun visualizers, lyrics, art, and a human connection to the live DJs on KEXP, all for free.

This actually reminded me how much the Spotify UX irritates me. I would love to stare at a spectrogram or to be able to change the source that Spotify is using for lyrics, or replace album artwork.. Or listen without having to see all the content that Spotify's suggestion algorithms are serving me today if I don't want to. Or rearrange the UI panels. Remove stuff I don't want to see. Change colors.

Basically I would love to be able to pipe my Spotify streaming through foobar2000.

Alas. This only used to be possible:

Spotify deprecated the library that was used to implement playback in this component.
There are no viable Windows alternatives that could be used to replace it, hence this project is suspended until such alternative appears.

Live radio has been fun to rediscover though. Give it a try!

midinous-scale-loop

Been wanting to try this music software thing out for a while.
Midinous
Finally got it recently!

It's fun to mess with but I really dunno how music making works man.

The main portion of this is just a basic scale arranged in a loop with somewhat random spacing between each point.
The scale is G Major. The notes go up the scale, then back down, and then it does the arpeggio. The scale starts with the top left point.

The blue-circled portions are loops meant to randomly hold some of the "travelers" outside of the main loop for a random amount of time. Travelers are the things that move around and activate the points that play sounds.
The cyan-circled points will randomly decide whether to send a traveler to one of these "holding" loops or not. The holding loops are muted so no sound plays while the travelers are "held" away.

The "X" thing in the middle bottom of the loop (I point it out at 1:45 in the video) is a "terminator", configured to let travelers pass through only 24 times. After 24 travelers pass through the point, no more are allowed to pass, so the next time they reach the terminator they stop there. Eventually the "song" ends from this.

So this is the G Major scale (+arpeggio) played in rounds with random timing, by 4 players spaced randomly, with the random spacing shifting by random amounts at random times, where the song lasts for a sorta random duration.

qud-caves-caaaw

I've been playing this game called Caves of Qud.
Let me explain this screenshot cuz it's wild.

This game is a roguelike in the "classic" sense. (See games like Brogue)
So the entire game world is a flat grid with very simple graphics, and ALL of the gameplay is turn-based. Nothing happens unless you take some action (like moving, attacking, casting a spell, resting, etc). You can always plan out your next move.

The main window is the game view. The top left of that window shows my character standing in a cave, near the stairs that led down from the floor above. The torch I'm holding lights up some of the tiles. On the right is a log of stuff that happened over the past few turns. There's info about a fight that just occurred, involving a cannibal and a skunk. Skunk's still present, in the lower-right portion of the area lit by my torch.

So here I'm inspecting a club dropped by a cannibal that I finished off after it stumbled out of a cloud of bright green acid emitted by the skunk it attacked. The acid has killed some cave flora and melted a hole in the shale cave wall.

The club I'm inspecting is painted.
When the cannibal was swinging it at me, I assumed this just meant it was red or green or orange or something,
but no!

The last few entries in the event log on the side show my character taking note of a historic site I've just learned about, and some info about the ancient sultan Polyxerhim IV. I've even received a quest to go visit the site.
This all happened because the club is painted with a whole scene from the life of this sultan. The scene gets an entire paragraph in the object description. Down at the bottom you can also see that this club would give me +40 reputation with the Flock of the Wife to Caaw-caaaw-caaw.

I have no idea what this means! But it sounds like a good perk to get from the painted club I looted from the skunk acid-weakened cannibal I finished off. This lil chunk of painful wood just exudes history and import I guess. It should probably go in a museum, but I might need to hit a skunk with it instead.



This game has some unique vibes.
What I've seen so far of the setting and general world lore is fun, and the writing style for all the in-game descriptions is interesting:

The setting has that eclectic sci-fantasy blend going on where the world has been around long enough for civilization to rise and fall long ago, so now you can have your magic robot villages or whatever. Swords and magic and bows ..and guns and lasers and genetic mutations. You find a weird artifact in a cave and the local village tinker identifies it for you as ..a battery cell. You pay him in freshwater, because apparently the apocalypse made the world extra salty. No but like extra extra salty.

The main hesitation I have right now is run length..
Cuz so far it plays like a whole big RPG only I can't save-scum and there's permadeath.
I am multiple hours into my first run right now and feel like I haven't scratched the surface of basically anything!
So it might be pretty devastating to die in this game.

They do have an alternative gamemode called "Roleplay" mode where you're allowed to save at settlements though, so if the permadeath gets annoying I guess I'll switch to that to experience the whole main questline.
Apparently the main quest is good!

review-the-sunlit-man-brandon-sanderson

This was decent!
It's in an odd place, where the merits of the story on its own have to vie for space alongside some new meta-story (Cosmere) stuff. You've got hints to connections with other stories on other worlds, teasers for events in the past that other books haven't gotten to yet, and the central mystery of the main character. Then you've got the plot for this story itself, a cast of ~5 important characters, a brand new setting with a brand new magic system, an intentionally-breakneck speed for pacing,
and about 450 pages of real estate for all of that.

Some things feel understandably a bit under-developed, but it still mostly works. The aesthetic of the setting is strong. The Cosmere connections are genuinely interesting. The internal dynamics of the main character are good, and his arc (though straightforward) is pretty satisfying. I wish Sanderson had included the comparison to (spoiler) somewhere in the Acknowledgements, instead of just in the Postscript, because it hadn't occurred to me before and I think it would've helped frame my expectations better going in.

Rated 3/5

drop-cstm80-review

Note: This was originally posted to Drop's website as a review for their "Signature Series Ryokucha Keyboard", which was a CSTM80 pre-configured with a green faceplate, a particular keycap set, and gateron yellow switches. The Drop store has effectively shut down since then, and while old product listings and community features (like reviews) stayed up for a little while, it looks like they've finally taken those down too. This review used to live at this URL but that now redirects to Drop's current homepage, where they're basically just an ad display for the few brand collab-based products of theirs that remain. As of right now you can still buy the CSTM80 via Corsair under the new name "Corsair One CSTM80". I dunno if they still sell the faceplates separately. This was a pretty disappointing development tbh, Drop had some cool products for a while, and the CSTM80 would still be highly recommended by me if it wasn't in this weird limbo state where it feels like Corsair doesn't want to fully support it as a platform the way Drop did. These days I'd lean toward recommending Keychron for getting into mechanical keyboards. Anyway, here's my original review relatively un-edited from the copy I saved in my notes back in 2024. (This note written 2026-08-23).

This keyboard has been an excellent introduction to custom mechanical keyboards for me!

(Desk mat pictured: Drop + Noctua Desk Mat, Blueprint version)
(2026 edit note: I dunno if you can buy this deskmat anymore. That link is dead.)

OVERALL BUILD / ASSEMBLY:​

Feels great! It's got a hefty weight that keeps it firmly planted on my desk. The case is not creaky when typing. The metal plate on the bottom is pretty fun. My keycaps came assembled properly, and the out-of-the-box experience was pretty flawless. The included USB-C cable was nothing special, but it was long enough for me, and there are lots of options out there for fancier or longer USB-C cables.

I have two notes/wishes about the build:

  1. I noticed at least one other Drop prebuilt model has magnetic detachable feet. I wish the CSTM80 had those! Adjustable height would be fun.
  2. Similarly, at least one other Drop prebuilt offers more than one USB C port for connecting to your computer on either the back-left OR back-right side. This board only has a connection port ont he left side of the back face. Keep this in mind for your setup!

KEYCAPS:​

The included Jasmine keycap set looks lovely in person, and goes perfectly with the CSTM80 green base.
The DCX profile on these keycaps is nice and familiar, nothing too wild.

(2026 edit note: As of 2026-08-23 the Drop DCX Jasmine Keycap set is actually still sold through Amazon, dunno if you can get it through any other storefront.)

My shipment included what appears to be the complete packaging and all unused keycaps in the Jasmine Keycap Base kit.
This is super useful!
If I want to throw these keycaps on a differently-formatted keyboard, or add a numpad later on, I'm prepared! It also means I have somewhere to put these Jasmine keycaps if I want to throw on another set for a while.

LIGHTING:​

The LED lighting is pretty subtle with the included keycaps, which I personally enjoy.

The Jasmine keycaps have no translucent portions themselves, so the south-facing LEDs just appear to light up the tiny gaps at the "bottom" of each row of keys. The LEDs offer very good customizability, letting you step through full hue, saturation, and value for solid colors. There are also tons of animations (many of which will use your custom HSV selection).

Doing this all through hotkeys is a little clunky, but it's mostly a set-and-forget thing for me anyway, so it works! You can see the hotkeys listed here (2026 edit note: not anymore! dead link) though I will note that on my unit I had to use the right "Super" key instead of the Fn key to work the hotkeys.

I haven't yet tried this board with translucent keycaps, but from looking at the bare switches with LEDs enabled, I feel like this use case should work at least well enough. You could potentially look for fully-clear switches for more light.

(Note that this image does not have the LEDs on full brightness.)

SWITCHES:​

I'm enjoying the Gateron Yellow KS-3 linears so far!
I knew going in that these switches were going to be smooth and not clicky. They still sound very satisfying when pressed, especially if I'm pressing the keys fully. I've read that pre-lubed switches often feel better with aftermarket lube manually applied, but I have not felt a need for this yet. I'm inexperienced though, so others may disagree.

SWAPPING KEYS:​

I have not yet tried to swap the switches themselves, but I was recently able to swap out my keycap set!

(Keycap set pictured: Drop + biip MT3 Operator)
(2026 edit note: dead link, I don't see these on amazon. The biip website still links to Drop saying they're available, but they're not. Maybe contact them if you're extra curious?)

The included keycap puller kept this process nice and straightforward.
The tray included with the Jasmine set helps things stay neat, and the overall build is very tidy under the keys.

There aren't too many places for dust to stick to, so a simple air dusting got rid of everything for me.

My one hurdle with this part of the experience was the fact that this keyboard has an F13 key.
From what I can tell, this isn't generally considered standard on an 80%/Tenkeyless keyboard layout, so not every keycap set will have a "nice" solution for it. For example, the Operator set in the image above only had repeat keys for any extra spots on that top row. I ended up using a repeat of their "insert" symbol.

This extra key should be useful if you feel like setting up a fun macro or throwing an artisan keycap over there or something, though!

SOFTWARE/FIRMWARE:​

Since this is a Drop CSTM80, it uses the Drop Keyboard Configurator software for customization and firmware flashing. I haven't messed around with this much, but it seems at least pretty good!

One quirk is that the software never recognizes my keyboard right away when I launch it. Instead, I always have to launch the software, then unplug and re-plug the keyboard to get it to show up.

The one thing I've tried to do in this software that I wasn't immediately able to figure out set up a shortcut for Fn+F13 to put my (Windows) computer to sleep. I've seen dedicated "sleep" buttons on a lot of other keyboards, but I never found Windows Sleep as a shortcut option in the software. I could have just missed it, not sure.

(2026 edit note: I dunno if there's an easy public way to get this software anymore. Right now I can't even find it via the "Corsair One CSTM80" page. I need to flash some other firmware on my board soon using the copy of the Drop software that I already have.)

CONCLUSION:​

I'm very satisfied with this!
If you're thinking about getting into mechanical keyboards, this or any similar Drop CSTM80-based prebuilt is probably a good buy!

(2026 edit note: Unless Corsair commits to continued sale of the faceplates and to keeping the software publicly available, or otherwise just flashing these with a different firmware like QMK, I can't call this a good buy anymore. This makes me sad.)
